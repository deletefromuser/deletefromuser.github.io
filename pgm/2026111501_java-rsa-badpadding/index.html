Java RSA 加密 BadPaddingException 修复

2026-11-15 22:00
Tags:
  • java
  • rsa
  • tip

原始配置

Cipher.getInstance("RSA")

传输到另一台服务器中解密时报错

javax.crypto.BadPaddingException: Padding error in decryption
	at com.sun.crypto.provider.RSACipher.doFinal(RSACipher.java:387)
	at com.sun.crypto.provider.RSACipher.engineDoFinal(RSACipher.java:451)
	at javax.crypto.Cipher.doFinal(Cipher.java:2168)

背景

刚更新了 jasypt 的加密方法，添加了新的 BouncyCastle 的 loader 以支持新的加密算法

排查过程

  1. 发现使用 java 直接加密出密文，再拿密文在另一台服务器中可以解密
  2. 在 web 服务器中加密的密文无法解密，且在相同明文的情况下每次密文都相同，本地执行和不经过 web 服务器直接执行 java 时每次生成的密文都不一样
  3. 打印出 Cipher 的 provider 后，发现直接执行时 provider 为 sunjce，在 Web 服务器中为 BC

原因

rsa 默认加密 provider 被替换

解决方案

Cipher.getInstance("RSA/ECB/PKCS1Padding", "SunJCE")
